# Zomato Food Delivery Performance Analysis using Python

Food delivery services depend on timely and efficient deliveries to maintain customer satisfaction. However, delivery times can vary due to several operational and environmental factors, including travel distance, weather conditions, traffic density, vehicle type, and order-related characteristics. Identifying which factors have the greatest influence on delivery performance is essential for improving service efficiency and reducing delivery delays. This project addresses the problem of understanding the key factors associated with variations in Zomato's food delivery time using data-driven analysis.

Number of Records and Variables - 38,964 x 26

Nature of Variables - Numerical, categorical and datetime features 

Dataset Url - https://huggingface.co/datasets/allenborochin/zomato_delivery_EDA/tree/main

**Aim** - This capstone project aims to analyse Zomato's food delivery performance in India and identify the key factors that influence the time taken to deliver an order.

**The final insight of the analysis** - Food Delivery efficiency depends more on the conditions encountered during the delivery journey—such as distance, traffic, weather, location, and workload—than on the time taken to initiate the delivery.
